## Как пользоваться

1. Открой свой **курс** → **предмет** (таблица ниже).
2. В предмете посмотри `README.md` — что лежит в папках и контакты препода.
3. Открой `дз/ДЗ.md` — **что сдать**, в каком формате и к какому сроку.
4. Условия заданий — рядом в `дз/`. Готовые работы других — в `дз/готовые/`.
5. Свой вариант почти везде = номер в [`Варианты.md`](Варианты.md). Если в `ДЗ.md` написано иначе (например, физика) — делай как там.

---

## Структура

```
1_course/{Предмет}/
  материалы/        ← лекции, методички, литература, ПО
  доп-материалы/    ← конспекты, расшифровки пар
  дз/
    ДЗ.md           ← что делать / формат / срок
    …               ← условия
    готовые/        ← уже сделанные работы
  README.md         ← оглавление предмета
```

Пустые папки не создаём.

## Как добавлять материалы

1. Сделай ветку с названием, соответствующим твоей фамилии, положи файлы в нужную папку предмета.
2. Открой **Pull Request**.
3. В `main` пушим **только после ревью владельца репозитория** — напрямую в `main` не пушим.
